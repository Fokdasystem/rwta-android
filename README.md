# RWTA — Roulette Wheel Trajectory Analyzer

This project is a research-oriented Android application for analyzing geometric structure in European roulette outcomes.

## Current status

This repository contains the first working phase for RWTA:
- Android project scaffold
- Jetpack Compose UI
- manual input of results 0–36
- geometry calculations for wheel transitions
- local Room persistence
- unit tests for core logic

## Build instructions

1. Install Android Studio and Android SDK 34.
2. Open this project.
3. Sync Gradle.
4. Run the `app` module on an emulator or physical device.

## Research note

This tool is intended for statistical investigation and not as a betting recommendation or guaranteed win mechanism.
